Where the project stands

JConnect is an early beta, released in September 2026. It works day to day across Windows, macOS, Linux and Android, and it is honest about what it cannot do yet. Anyone writing about it should know three things up front:

  • The Windows build is not code-signed and the macOS build is not notarized, so both operating systems warn on first run. This is a cost and paperwork gap, not a technical one, and it is being addressed.
  • The Android app is signed with a development key and is not on Google Play. It installs from the website.
  • Linux machines can be controlled in X11 sessions only. Wayland is not supported yet.

The full list is on the About page and in the docs. Please quote these limits rather than discovering them mid-review; they are deliberately published.

One line

JConnect is a remote-device app for Windows, macOS, Linux and Android with no IP addresses, no port forwarding and no required account: install it, pair once, press Connect.

Fifty words

JConnect is remote-desktop software built on one rule: remote access should be as
easy as using a computer normally. Computers on a network find each other, pair once
with a six-digit code, and connect. Every session is end-to-end encrypted, and no
account is needed to use it at home.

A hundred words

JConnect is a remote-device app for Windows, macOS, Linux and Android that removes
the setup step from remote access. There are no IP addresses to find, no ports to
forward, no VPN profile to configure and no account to create: two computers on the
same network discover each other, the user pairs them once with a six-digit code, and
presses Connect. Away from home, JVPN carries the session over a relay that can only
pass encrypted bytes. It also includes SSH, Remote Desktop routing, encrypted device
sync, and an Android app that turns a television into a client. It is free during the
beta.

For writers

What is actually different

Remote-desktop software is a crowded category. These are the points a reviewer is most likely to find worth writing about, stated without exaggeration.

Nothing to configure, and no account at home

Local use requires no sign-up, no ID number to read aloud, and no network settings. Machines announce a name and a public key, pair once with a six-digit code, and are then recognised by key rather than address. The pairing code never crosses the network — it becomes a scrypt proof bound to a single connection.

A VPN that is not a VPN

JVPN reaches machines away from home without installing a network adapter, so other applications on the computer do not see a VPN and it needs no administrator rights. It carries only JConnect, SSH and RDP traffic to the user’s own machines — a narrower promise than a general-purpose VPN, and a smaller attack surface.

The relay cannot read anything

Sessions away from home pass through a relay that handles encrypted bytes only, with dialling gated by one-minute tickets and limited to devices on the same account. Account sync is encrypted on the device before upload, which means a forgotten password genuinely cannot be recovered — a tradeoff worth putting to readers.

Your television is a client

The Android build detects TVs and switches to a layout for a directional remote: arrows move the pointer, OK clicks, holding OK right-clicks or drags. Computers are listed by name, so nothing has to be typed with a remote control. Few remote-desktop apps treat this as a target rather than an accident.

It brings its own VPN integrations

Tailscale, Twingate, ZeroTier, WireGuard, FortiClient and Windows VPN can each be started and imported from inside JConnect, which then checks what each imported machine offers. It never edits a VPN’s own configuration.

The server is yours if you want it

Accounts, sync, relay and TURN are one Node.js application that runs against SQLite or PostgreSQL. Self-hosting is a documented path, not a hypothetical one.

Trying it

Review builds

Every build is public: the download page serves the current release for all four platforms, and each download is published alongside its exact size and SHA-256. There is no reviewer gate and no time limit.

Two notes that save time in a review:

  • Because the builds are unsigned, Windows SmartScreen and macOS Gatekeeper both interrupt the first launch. The install docs give the exact steps.
  • To test the away-from-home path (JVPN), an account is needed on a JConnect Cloud server. Get in touch and one can be arranged, or run the server yourself — it is a documented npm start.
Style

Using the name

  • Write it JConnect — one word, capital J, capital C. Not “JConnect” with a space, not “Jconnect”, not “J-Connect”.
  • The tagline is Open. Connect. Work. The name expands to Just Connect.
  • Call it a remote-device app or remote-desktop software. It is not a VPN, although it includes one for its own traffic.
  • Other unrelated products and organisations use the name JConnect. If ambiguity is possible in your publication, JConnect (remote desktop software) disambiguates it.
