Get started

Overview

JConnect makes any of your computers feel like the one in front of you. Install it, pair once, and press Connect. There are no IP addresses, ports or VPN settings to learn, and you don’t need an account.

  • Computers run the JConnect app. It shares that computer with your paired devices and connects you to your other computers.
  • Phones, tablets and TVs can use JConnect in their web browser, served by your JConnect computer. Android also has its own app.
  • Every connection is end-to-end encrypted, whichever network carries it: your local network, JVPN, Tailscale or another VPN.
Get started

Install JConnect

Windows

  1. Download the installer for Windows 10 or 11, 64-bit.
  2. Open JConnect-Setup.exe. It installs for your account without admin rights, adds Start menu and desktop shortcuts, and starts JConnect.
  3. The first time JConnect starts, Windows Firewall asks whether to allow it. Allow it on private networks so your other devices can reach this computer.

The beta isn’t code-signed yet, so SmartScreen may say “Windows protected your PC”. Choose More info → Run anyway.

Android

  1. Download the Android app on a phone or tablet running Android 8.0 or later.
  2. Open JConnect-Android.apk. The first time, Android asks you to allow installing apps from your browser or file manager.
  3. Open JConnect and tap Add Computer. Scan the code your computer shows under Settings → Use this computer from a phone, or type the computer’s address and the pairing code shown at the bottom of its JConnect window.

The Android app connects to your computers. It doesn’t share the phone’s own screen.

Linux

Download the .deb from the download page and install it with sudo apt install ./JConnect-Linux.deb. It works on Ubuntu, Debian, Linux Mint and other Debian-based systems on 64-bit PCs, and JConnect starts when you sign in. Paired devices can control a Linux computer in an X11 session, such as Ubuntu on Xorg. Wayland sessions aren't supported yet.

Mac

  1. Download the DMG for your Mac from the download page: Apple silicon or Intel. Apple menu → About This Mac shows Chip on Apple silicon Macs and Processor on Intel Macs. JConnect needs macOS 13 Ventura or later.
  2. Open the DMG and drag JConnect into Applications.
  3. Open JConnect. It isn’t notarized by Apple yet, so the first time macOS says it can’t check it. Close that message, open System Settings → Privacy & Security, and choose Open Anyway next to JConnect.
  4. So your paired devices can see and control the Mac, open Settings → Mac permissions in JConnect and turn on Screen Recording and Accessibility.

Raspberry Pi

The Raspberry Pi app is coming soon. Until then you can reach your computers from a Raspberry Pi through its browser, the same way as from a phone.

Closing the window

Closing the JConnect window keeps the computer available. JConnect stays in the system tray, and Start with this computer in Settings starts it in the background when you sign in.

Get started

Pair a computer

You pair each device with a computer once. After that, the computer recognizes the device by its key and you just press Connect.

  1. Install JConnect on both computers.
  2. On the computer you’re using, open Add Computer. JConnect computers on your network show up there by themselves.
  3. Choose the computer, then enter the pairing code shown at the bottom of the JConnect window on that computer and press Pair.
  4. Press Connect. You won’t need to pair again.

Ask for permission instead

If you can’t see the code, press Ask for permission. Someone at the other computer gets a prompt. Both screens show the same short verification code: they check it matches, then press Allow. Ticking This is one of my own devices marks the device as yours.

The pairing code never leaves your device. JConnect proves it knows the code over the encrypted connection, so an eavesdropper can’t learn or reuse it.

Computers that don’t show up

Under Add Computer → Other ways to connect, type the computer’s name or address and press Find. You can also import computers from Tailscale and other networks.

Get started

Connect and work

Press Connect on a computer in My Computers. The remote computer fills the window, with sound from Windows computers.

Controls

Move the pointer to the top edge, or press Ctrl Alt Home (Control Option Home on a Mac), to show the controls:

  • ← Home goes back to your computer list.
  • Display switches between the remote computer’s screens.
  • Devices switches to another of your computers.
  • ⋯ sets the quality, full screen and zoom, or disconnects.

Quality

SettingWhat you get
AutomaticSharp on your local network, Balanced everywhere else.
SharpFull resolution at 30 frames per second, up to 10 Mbps.
BalancedUp to 1920 pixels wide at 30 frames per second, up to 5 Mbps.
Data saverUp to 1280 pixels wide at 15 frames per second, up to 1.5 Mbps.

The computer you connect to also lowers the quality by itself when it’s working hard or running hot, and raises it again when it cools down.

If the connection drops

JConnect reconnects by itself, trying every path it knows. If a paired computer is asleep and supports Wake-on-LAN, pressing Connect wakes it. You can also right-click it and choose Wake.

Organize your computers

Right-click a computer for more options:

  • Rename… changes its name, and Whose computer is it? groups computers under a person’s name.
  • Connect using… picks the network JConnect uses for it.
  • Create Shortcut puts a shortcut on your desktop that connects with a double-click.
Get started

Phones, tablets and TVs

Android, iPhone, iPad and TVs with a modern browser can use JConnect without installing anything. On Android you can also install the app, which scans the code for you.

  1. On the computer you want to use, make sure Remote access and Allow phones and browsers are on in Settings.
  2. Open Settings → Use this computer from a phone. JConnect shows a QR code and an address.
  3. Scan the code with the phone’s camera, or type the address into a tablet or TV browser. Then tap Pair.

The phone needs to be on the same network as the computer, or on the same private network such as Tailscale. On touch screens, tap to click and pinch to zoom, and open ⋯ → Keyboard to type.

The phone page itself loads over plain http on your local network, but the connection to the computer is still end-to-end encrypted. On networks you don’t trust, use the desktop app.

Networks

JVPN

JVPN is JConnect’s own network. It’s on by default, so you don’t need another VPN.

  • At home, devices connect directly over the local network.
  • Away from home, sign in to your JConnect account on both devices. Each computer keeps an outgoing, signed connection to the JConnect Cloud relay, and your other devices reach it through that relay.
  • The relay only passes encrypted bytes. It can’t read, change or impersonate anything. Only devices on your account can see or dial each other, and every dial uses a one-minute ticket.

JVPN carries remote desktop, SSH and Remote Desktop (RDP) to your JConnect computers. Choose what each computer shares under Settings → Share through JVPN. JVPN is built into JConnect and doesn’t install a system-wide network adapter.

When JConnect imports machines, it checks what each one offers (JConnect, SSH or Remote Desktop) and adds the ones you choose to My Computers.

When you press Connect, JConnect starts the network that computer uses and asks for administrator permission only when the VPN needs it. It never changes a VPN’s own settings. Set a computer’s network with Connect using…, and the default for computers that aren’t nearby with Settings → JVPN → When a computer isn’t nearby, use.

Networks

SSH

  • Add SSH host, or import every named host from ~/.ssh/config.
  • Open SSH terminal on a JConnect computer reaches its SSH server through JVPN. Turn on Settings → Share through JVPN → SSH on that computer, and set its SSH port if it isn’t 22.
  • Sign-in tries your SSH agent, then this device’s own JConnect SSH key, then asks for a password. Copy my SSH key copies the public key so you can add it to a server.
  • A host’s key is remembered the first time you connect. If it changes later, JConnect stops and tells you.

SSH to a JConnect computer needs an SSH server running on it, for example OpenSSH Server on Windows.

Networks

Remote Desktop

  • Add Computer → Import Remote Desktop file adds an existing .rdp connection.
  • Open with Remote Desktop opens a computer in Windows Remote Desktop. On a Mac, JConnect opens the .rdp file with your Remote Desktop app. On Linux it uses FreeRDP or Remmina.
  • To reach a Windows computer’s Remote Desktop from outside your network, turn on Settings → Share through JVPN → Remote Desktop on that computer.
Security

How it’s secured

Every connection uses JConnect protocol v2, whichever network carries it.

  • Encrypted end to end. Each connection runs a fresh X25519 key exchange. Messages, remote-control input, SSH and Remote Desktop data are sealed with XSalsa20-Poly1305. Frames are numbered, so altered, replayed or reordered data closes the connection. Screen and sound travel over WebRTC, which is DTLS-SRTP encrypted, and its keys are signed inside the channel.
  • Both sides prove who they are. Every device has an Ed25519 identity key, and its ID comes from that key. The computer signs each connection’s transcript, and the other device checks it against the key it paired with. The connecting device signs the same transcript, so a stolen or replayed message can’t be reused.
  • Secrets never cross the network. Pairing codes and passwords become scrypt proofs bound to one connection.
  • Stored safely. Device keys, API keys, account tokens and SSH keys are encrypted with the operating system’s key store.
  • Least exposure. Discovery announces only a name and public key, and you can turn it off. The app’s windows only get the permissions they need, and the Windows app is hardened with Electron fuses.
Security

Trusted devices

Settings lists every device that can use this computer. For each one you can:

  • Choose Full control or View only.
  • Mark it as Mine, which matters for Travel Mode.
  • Remove it, which revokes its access right away.

Connected now shows active sessions, each with a Disconnect button. Recent activity under Security logs pairing, connections and anything suspicious.

Extra protection

  • Require password adds a password to every connection. Paired devices are already protected without it.
  • Trust my account’s devices lets devices signed in to your JConnect account connect without pairing. It’s off by default.
  • Hide from nearby devices stops announcing this computer on the local network. Paired devices can still connect.
  • Allow phones and browsers serves the JConnect web page for phones, tablets and TVs on your network.
Security

Travel Mode and Emergency Lockdown

Travel Mode

Turn on Travel Mode when you leave a computer unattended. New pairing turns off, streaming is capped at Balanced (Data saver on battery), and JConnect is stricter about suspicious activity. Only my own devices lets only devices marked as yours connect.

Emergency Lockdown

JConnect rates suspicious activity within a 10-minute window:

LevelWhat happensFor example
LowThe attempt is blocked and logged.An unknown device tries to connect.
MediumPairing pauses for 15 minutes and you get a notification.3 wrong pairing codes or 5 wrong passwords from one device, or a connection that fails a security check.
HighEvery session ends and remote access turns off until you restore it.A device pretends to be one you trust, 10 wrong codes or passwords in total, or one device failing security checks 3 times.

In Travel Mode these limits are halved, and repeated attempts by unknown devices count as medium. To end a lockdown, review Recent activity and press Restore Remote Access in Settings.

Emergency shutdown

If you turn on Emergency shutdown, a high-level event in Travel Mode also shuts the computer down safely after a 60-second warning.

Account

Account and sync

An account is optional. Click the person icon at the top of JConnect to sign in or create one on your JConnect Cloud server.

  • Your password stays on the device. It becomes two keys: one the server checks, and one that encrypts your data before upload.
  • Computers, SSH hosts and your list of devices sync between your devices, and the server only stores them as ciphertext.
  • Two-step sign-in with an authenticator app is available under Account.
  • Signing in makes your computers reachable through JVPN away from home.
Account

Host JConnect Cloud

JConnect Cloud handles accounts, sync, the JVPN relay and optional TURN. There’s no hosted service yet, so you run your own. The server is part of the JConnect source code and needs Node.js.

cd server/cloud
npm install
npm start          # listens on port 47900

Options

VariableWhat it does
TLS_CERT, TLS_KEYServe https with this certificate and key. You can also put the server behind a reverse proxy.
TURN_PUBLIC_HOSTTurns on TURN to relay remote-desktop media when two networks block direct connections.
TURN_PORTThe TURN port. The default is 3478.
JCONNECT_CLOUD_DBWhere the accounts database is stored. The default is server/cloud/data/cloud.db.
 
TLS_CERT=/etc/jconnect/cert.pem TLS_KEY=/etc/jconnect/key.pem TURN_PUBLIC_HOST=cloud.example.com npm start

Accounts, devices and sessions are stored in an SQLite database, which needs Node.js 22.13 or later. Accounts from an older cloud.json are imported the first time the server starts. JConnect only accepts http:// cloud addresses on private networks. Everywhere else, use https.

Troubleshooting

A computer doesn’t appear under Nearby

  • Check both computers are on the same network, and that JConnect is running with Remote access on.
  • Allow JConnect through the firewall on private networks. See Network ports.
  • Check Hide from nearby devices is off on the other computer.
  • Use Add Computer → Other ways to connect with its name or address, or import it from Tailscale.

“Pairing is paused for a little while”

Too many wrong codes or declined requests pause pairing for 15 minutes. Pairing is also off in Travel Mode and during Emergency Lockdown.

I can’t reach a computer away from home

Sign in to the same JConnect account on both devices, keep Use JVPN on, and check the computer is awake and online. Or use a VPN you already have, like Tailscale.

The phone page won’t open

Turn on Allow phones and browsers, put the phone on the same network or Tailscale network, and type the address exactly as JConnect shows it, including http:// and the port.

I can see the screen but can’t control it

Check your device has Full control on that computer. On Windows, apps running as administrator and UAC prompts ignore input from JConnect unless JConnect also runs as administrator.

Reference

Known limits

  • The Windows, Mac, Linux and Android apps are early betas. There are no automatic updates yet, so download new versions from the download page.
  • The Mac app isn’t notarized yet, so macOS asks you to confirm it the first time. It doesn’t share the Mac’s sound yet.
  • Windows can’t be controlled on the secure desktop: UAC prompts, Ctrl+Alt+Del and the lock screen.
  • SSH to a JConnect computer needs an SSH server running on it.
  • Accounts, sync and JVPN away from home need a JConnect Cloud server that you run yourself.
  • Raspberry Pi and Apple TV apps are coming soon.
  • Camera sharing isn’t built yet.
