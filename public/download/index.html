Open JConnect on a phone, tablet or TV

01

Set up a computer

Install JConnect on the computer you want to use, and keep Remote access on.

02

Show the code

In JConnect, open Settings → Use this computer from a phone. It shows a QR code and the address.

03

Open it and pair

Scan the code with your camera, or type the address on a tablet or TV. Then tap Pair.

Install once.
Connect from your other screens.

Start with the computers you want to reach. Your phone, tablet and TV connect to them.
