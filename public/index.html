JVPN

Your own network.
No VPN required.

At home, devices talk directly. Away from home, they meet through the JConnect relay — which only ever carries encrypted bytes it can’t read, change or impersonate.

  • Direct on your local network, relay only when needed
  • Only devices on your account can see or dial each other
  • Carries remote desktop, SSH and Remote Desktop
  • One-minute dial tickets instead of long-lived tokens

Security

Simple on top.
Serious underneath.

Every connection is end-to-end encrypted and both sides prove who they are — whichever network carries it.

protocol v2 
// 1. Fresh keys for every connection
client → client-hello  { eph: X25519, nonce }
host   → server-hello  { id, key: Ed25519, eph, sig }

// 2. The computer signs this exact conversation
th  = SHA-512(eph ‖ nonce ‖ eph ‖ nonce ‖ key)
sig = Ed25519.sign("jconnect-v2-server:" + th)

// 3. Separate keys each way, bound to th
keys = X25519(ephemeral) → SHA-512 → c2s, s2c  ✓ encrypted
// The code is proven, never sent
proof = scrypt("482193", salt = hash(th), N=32768)

phone → pair { proof }
host  → checks proof for this channel only  ✓ paired

// "Ask for permission" shows the same code on both screens
both  → Make sure JConnect shows 482 193
// Every message after the hello
frame = counter(8) ‖ XSalsa20-Poly1305(kind ‖ payload)

counter  41  ✓ accepted
counter  41  ✗ replayed — channel closed
tampered     ✗ authentication failed — channel closed

A terminal,
wherever it lives.

Open SSH to any host, to machines on your VPN, or to your JConnect computers through JVPN. Host keys are remembered the first time, and a changed key stops the connection.

  • Sign in with your agent, your JConnect key or a password
  • Import every host from ~/.ssh/config
  • Encrypted inside JVPN, even across the internet
