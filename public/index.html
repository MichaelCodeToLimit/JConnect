Simple on top. Serious underneath.

Encrypted end to end
X25519 key exchange and XSalsa20-Poly1305 on every path.
Proven identities
Ed25519 device keys catch a changed computer before it is trusted.
No secrets on the wire
Pairing codes and passwords become scrypt proofs for one connection.
Optional account
Sync computers and SSH hosts. Everything is encrypted before upload.
// Fresh keys for every connection
client → client-hello  { eph: X25519, nonce }
host   → server-hello  { id, key: Ed25519, eph, sig }
// The computer signs this conversation
sig = Ed25519.sign("jconnect-v2-server:" + th)
keys = X25519 → SHA-512 → c2s, s2c  encrypted
// The code is proven, never sent
proof = scrypt("482193", salt = hash(th), N=32768)
phone → pair { proof }
host  → checks proof for this channel only  paired
// Every message after the hello
